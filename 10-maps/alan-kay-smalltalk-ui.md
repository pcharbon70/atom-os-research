# Alan Kay, Smalltalk, and Visual Computing

## Scope

This map connects Alan Kay's personal-dynamic-medium vision, the collective
Smalltalk implementation, the distinct Xerox Star desktop lineage, HCI
analysis, representative current desktop architecture, and the proposed Atom
OS visual-computing model. It treats visual technique, semantic architecture,
authorship, protection, and recovery as separate questions.

## Open questions

- Can a project-level semantic protocol remain open-ended enough to support
  not-yet-invented media without turning into one privileged universal schema?
- Can non-experts move from manipulation to symbolic modification safely and
  transfer that understanding to new tasks?
- Which UI state is durable meaning, which is reconstructible presentation,
  and which interaction state must be discarded across a restart?
- How should offline and distributed edits merge without confusing data
  reconciliation with authority delegation?
- What compositor, input-broker, accessibility, and live-tool mechanisms need
  recovery reserve, and which can remain ordinary restartable services?
