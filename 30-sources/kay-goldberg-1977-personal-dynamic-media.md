# Personal Dynamic Media

## Reference

Alan C. Kay and Adele Goldberg. “[Personal Dynamic
Media](https://doi.org/10.1109/C-M.1977.217672).” *Computer* 10(3), pages
31–41, March 1977. The full text was checked in the [New Media Reader
reprint](https://www.newmediareader.com/book_samples/nmr-26-kay.pdf).

## Contribution

The paper reports the Learning Research Group's Dynabook and Smalltalk work as
a unified medium for text, graphics, animation, sound, programming, filing,
communication, and simulation. It explains why a computer is a
*metamedium*: it can represent existing media while letting users invent new
ones and make tools within the same environment.

## Method

Kay and Goldberg combine a design argument with descriptions and screen images
of systems built by researchers, children, teachers, artists, musicians, and
other domain specialists. The cases demonstrate expressive breadth and
interaction mechanisms; they do not provide comparative or controlled
measurements.

## Findings

- Smalltalk is presented simultaneously as programming system, interactive
  memory, editor, and expressive medium for words, images, animation, music,
  and models.
- The active metamedium can answer queries and support experiments rather than
  only transmitting a fixed author's representation.
- Instrument-like responsiveness is a core requirement: visible effects must
  follow user action without a perceptible pause.
- Every description or object can be displayed and edited. Pointing and menus
  select an object and its operation; multiple windows expose several parts or
  levels of refinement at once.
- A dynamic document is a related collection of sensory objects. Each frame
  supplies an editor appropriate to its medium, while filing and cross-linking
  organize the whole.
- Animation, music, drawing, and simulation can be controlled either manually
  or by programs. Simulation is the unifying operation rather than one
  separate application category.
- The authors reject trying to anticipate every feature. They propose a
  general medium, reusable tools, and approachable tool-making so users can
  mold the machine to unanticipated needs.

## Relevance

This is the clearest primary statement of Kay and Goldberg's intended whole.
Windows, menus, documents, editors, and programming are components of one
user-extensible medium, not independent applications joined only by files and
clipboard formats. It supplies the baseline against which modern desktop
composition, toolkit, process, package, accessibility, and security boundaries
can be compared.

## Limits

The examples are selected demonstrations from a research community. They show
possibility, not population-wide learnability, security, resilience, or
maintainability. The paper's “ordinary user” aspiration should not be reported
as a demonstrated general outcome.
